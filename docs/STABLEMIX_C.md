# StableMix C technical note

This note describes the included DSP's normal AI path, not the non-stereo bypass or inference-failure fallback. Channel order is the foobar canonical `FL FR C LFE BL BR SL SR`.

Let L/R be the latency-aligned original stereo input on the model clock, D_L/D_R the Drums stem and O_L/O_R the Other stem. Source operands are float32. The code spells the coefficients as float literals:

```text
h = 0.70710678f
mid  = 0.5f * (L + R)
side = 0.5f * (L - R)
FL = h * (0.96f * mid + side)
FR = h * (0.96f * mid - side)
C  = h * 0.39597980f * mid
LFE = 0.0f
BL = h * 0.11f * O_L
BR = h * 0.11f * O_R
SL = h * (0.12f * D_L + 0.20f * O_L)
SR = h * (0.12f * D_R + 0.20f * O_R)
```

Front and Center geometry comes from original stereo; it is not recomputed from Vocals. Bass and Vocals have no separate positioning term in this mixer. This statement is about mixer inputs, not a claim that a learned separator perfectly isolates sources. Other has the upstream runtime's residual policy. Surround assignments remain fixed; there is no C/D switch, D routing, tuning file or stutter-memory scanner in the delivered DSP.

The mixer writes float32 on the 44.1 kHz model clock, the existing output adapter converts to host rate, and samples are cast to the host's `audio_sample` representation. The source keeps its exact expression order, but Release `/fp:fast` can transform evaluation. These displayed real-number formulas do not promise universal raw-bit equality with arbitrary Python evaluation orders.

Input is accumulated in 128-frame model hops. One previous-hop model alignment and existing adapter tails are retained. A dedicated high-priority non-MMCSS worker executes inference; the host caller waits for completion. This is not a non-blocking callback claim. ORT intra-op is one and spinning is disabled. Output generated by one input callback is batched; the initial/flush prebuffer target is 250 ms, with remaining data drained at playback end. `flush()` drops held output and resets state, and does not insert a chunk. Track-end marking is distinct from playback-end draining; see the offline qualification summary.

If model inference fails, the existing fallback is headroom-scaled aligned original L/R in the front channels with the other six zero. If the runtime is not ready at initialization, input bypasses. Neither mode supplies AI upmixing. Native non-stereo material is passed through rather than remixed by this AI design.
